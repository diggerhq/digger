description: "Scope drift checks by project"

Use this page to scope drift detection projects.

In Drift Service mode, set project scope in the OpenTaco UI when configuring drift.

For first-time setup of Drift Service mode, start with [Onboarding: Drift Detection + Remediation](/onboarding/drift-detection-remediation).

- On the Projects page in the OpenTaco UI, choose which projects drift detection should run against
- Save the schedule and notification configuration in the same flow
